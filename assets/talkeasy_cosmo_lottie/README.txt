TalkEasy Cosmo Avatar - Lottie-style image sequence

Contents:
- talkeasy_cosmo_avatar.json
- images/cosmo_pose_1.png through cosmo_pose_8.png

This is a Lottie JSON animation that switches between eight transparent PNG poses.
Keep the JSON and the images/ folder together when importing into a Lottie player.
Because this uses raster image assets, it is not a fully vector/body-part rig; it is
a lightweight pose-loop animation made from the generated character sheet.

For React Native / Expo, use lottie-react-native if your project supports external
image assets for the chosen workflow. Some Lottie hosting platforms require assets
to be embedded or packaged separately.
