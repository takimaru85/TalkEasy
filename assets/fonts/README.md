# TalkEasySchool

Nunito with exactly one glyph changed: lowercase **a** is the single-storey (infant /
school-print) form used when teaching children to read and write. Everything else — uppercase A
included — is Nunito's original outline, so size, stroke weight, rounded terminals and spacing
are unchanged.

**This letterform is opt-in per language, not global.** US English (the default) keeps Nunito's
ordinary double-storey **a** everywhere. A locale asks for the school-print form by setting
`letterStyle: 'single-storey'` (currently Filipino only) — see `src/i18n`. Nothing here changes
what English users see.

The new **a** is built from Nunito's own **d**: the stem's rounded cap is translated down to the
bowl's top (x-height + overshoot) and the glyph is scaled horizontally onto the width of **o**,
so it sits with the other round letters. Two weights are generated, matching the faces the
handwriting screens use: ExtraBold (tracing guide) and Black (the model letter above the canvas).

Two ways it is used, because react-native-svg resolves font families against fonts linked into
the native app and therefore ignores fonts loaded at runtime:

* the model letter above the writing canvas is ordinary RN text, using `Fonts.schoolBlack`
  (TalkEasySchool-Black.ttf, loaded by expo-font) for 'single-storey' locales and `Fonts.black`
  (plain Nunito) otherwise;
* the tracing guide inside the canvas is drawn from outlines in `src/adaptive/schoolGlyphs.ts`
  (generated by `scratchpad/fonttool/make-school-glyphs.js`), laid out by `schoolText.ts`.
  That module ships plain Nunito in `SCHOOL_GLYPHS` and the school-print **a** separately as
  `SINGLE_STOREY_A`; `layoutSchoolText(text, w, size, letterStyle)` swaps it in for the one
  character, so every other glyph is byte-identical between languages.

The rest of the app keeps unmodified Nunito.

Licence: Nunito is SIL OFL 1.1 (see `OFL.txt`). The OFL allows modification but reserves the
name "Nunito", which is why these files are named **TalkEasySchool**.

Regenerate: `scratchpad/fonttool/make-school-font.js` (opentype.js) — it reads the Nunito TTFs
from `node_modules/@expo-google-fonts/nunito` and writes the two files here.
